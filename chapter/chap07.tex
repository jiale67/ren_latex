\chapter{总结与展望}

\section{工作总结}
本文围绕复杂动态环境下移动机器人自主导航的实际需求，针对多源环境感知、定位建图、动态障碍物处理以及路径规划等关键问题，开展了移动机器人导航系统设计与应用研究。全文主要工作总结如下：

\begin{enumerate}[label=(\arabic*)]
\item 针对导航系统中多传感器数据统一表达的问题，本文确定了以Livox MID-360三维激光雷达和Orbbec Gemini335L双目深度相机为核心的感知配置，明确了两类观测在量程、精度和视场上的互补关系，并梳理了世界坐标系、机器人基坐标系、雷达坐标系和相机坐标系之间的转换关系，研究了双目深度相机成像模型、内参标定、传感器静态外参配置以及深度图反投影方法。在此基础上，将激光雷达和深度相机观测统一到机体坐标系，采用差异化体素融合与时间衰减形成稳定、去噪的局部点云表示，为定位、障碍检测和路径规划提供一致的空间数据基础。

\item 针对复杂室内与受限空间中结构重复、局部几何退化及里程计累积漂移问题，本文设计了基于FAST-LIO2与预建点云地图的定位方法。系统采用近似初值与ICP精配准相结合的启动对齐流程，并在地图坐标系下利用点到平面量测持续更新状态；同时设置固定地图的纯定位模式和允许增量更新的混合建图模式。第3章的仿真实验表明，在走廊、迷宫和圆柱体林三类场景中，地图约束模式的绝对轨迹误差相对纯里程计模式下降$77\%$以上，最大误差不超过$0.16\,\mathrm{m}$；在初值扰动控制在平移$1\,\mathrm{m}$、旋转$20^{\circ}$以内时，ICP初始对齐成功率为$99.5\%$；单帧平均处理耗时不超过$24.3\,\mathrm{ms}$，满足实时定位要求。

\item 针对机载计算资源有限、深度相机视场受限及单一检测器易受噪声影响的问题，本文构建了基于U深度图与DBSCAN点云聚类的轻量级障碍物检测跟踪方法。通过双向IoU校验融合两类检测结果，利用特征关联和恒加速度卡尔曼滤波维持目标轨迹，并采用“包围盒速度初筛—点云运动一致性复核”策略识别动态障碍物。在第2章融合点云的基础上，进一步通过射线遍历、对数几率更新与形态学膨胀构建局部占用地图。

\item 针对非凸障碍物包络占用过于保守以及动态环境中局部状态持续变化的问题，本文设计了基于神经距离编码的模型预测避障规划方法。该方法将避障与运动约束全部置于局部规划层，对上层参考路径仅要求可按弧长采样且末点为目标位置，因此A*、RRT或起终点直线均可作为参考路径来源；局部层引入点级障碍表示、恒加速度预测点流以及距离--分离方向编码器，以离线学习的几何映射替代在线重复求解点到凸轮廓距离问题，旨在减少粗粒度包络造成的可行空间损失。针对麦克纳姆轮全向底盘，局部规划采用以地图系笛卡尔平移速度和角速度为控制量的三自由度运动模型，该模型对状态与控制均为线性，滚动优化中无需对动力学作线性化，航向角作为可控状态与平移运动联合优化。平移速度与角速度分别采用二阶锥约束与箱式约束，以符合底盘平移与旋转不共享速度预算的物理特性；速度代价沿参考路径方向分解并对垂直分量降权，在保留横向自由度作为绕障手段的同时限制其过度使用。规划器输出的首个控制量经一次平面旋转转换为机体系速度指令，并配套设置求解超时、碰撞风险和目标到达等异常处理逻辑。针对该平台的轮廓尺寸重新生成了监督数据并完整训练了距离编码器，训练与验证损失量级相当。第5章已建立静态环境与复杂动态环境两类测试环境的统一实验协议，评价维度覆盖任务完成性、安全性、轨迹质量与实时性，性能结论须在实际日志补齐后给出。

\item 针对仿真环境难以反映真实量测缺失、定位漂移和底盘执行偏差的问题，本文在自研移动机器人平台上开展了实物实验验证。平台搭载三维激光雷达，集成预建地图定位、障碍检测与神经距离编码MPC规划模块，按机体系三分量速度接口驱动麦轮底盘，与仿真被控对象的运动学形式及编码器权重完全一致，验证了导航软件链路在真实感知与执行条件下的可运行性。第6章针对L型非凸障碍和多障碍组合环境给出了实验方案与记录表结构，当前材料可证明平台与场景已搭建、软件链路可运行，定量结论有待同场次同步日志补齐。
\end{enumerate}

\section{工作展望}
本文围绕复杂动态环境移动机器人导航系统的关键模块进行了设计与研究，但距离多场景、长周期工程化运行仍有进一步完善空间。后续工作可从以下几个方面展开：

\begin{enumerate}[label=(\arabic*)]
\item 完善真实复杂场景下的系统实验。后续可在制造厂房、仓储空间、地下设施、施工区域或应急救援环境中，围绕定位误差、建图精度、障碍物检测准确率、规划耗时、路径平滑性和任务完成率等指标建立更完整的评价体系，并开展多场景、多工况和长时间运行试验。

\item 提升多传感器融合在退化与干扰条件下的鲁棒性。复杂作业环境中可能存在弱纹理、强反光、粉尘遮挡、结构重复和机体振动等问题，单一传感器容易出现观测退化。后续可进一步融合激光雷达、视觉、IMU和轮式里程计等多源信息，引入在线外参校正、传感器健康评估与自适应权重调整，提高定位和感知系统对环境变化及传感器异常的适应能力。

\item 提升无先验启动与长期定位能力。本文预建地图定位依赖近似初始位姿和ICP局部收敛，后续可结合全局点云描述子、场景检索、回环检测或多源定位先验，实现无可靠初值条件下的全局重定位；同时研究地图变化检测与分层更新机制，降低长期作业过程中环境变化对固定地图定位的影响。

\item 优化动态障碍物预测与局部规划策略。当前方法主要基于恒加速度模型和显式几何约束进行动态避障，后续可结合交互感知的运动预测、风险场建模或时空占用预测，提高机器人面对突发动态目标、密集交互和遮挡恢复时的决策能力；还可研究网络模型压缩、优化问题热启动和自适应预测时域，以进一步降低神经距离编码MPC的在线计算开销。

\item 推进导航系统与具体工业及特种作业任务的深度结合。后续可将导航系统与物资转运、设备状态检查、目标抓取、环境侦察和应急处置等任务模块集成，建立任务分配、环境感知、路径规划、运动执行与异常恢复之间的闭环协同机制，从而提高移动机器人在不同作业场景中的实用性与迁移能力。
\end{enumerate}
